# SentryAI — Agentic Security Testing Toolkit

SentryAI is a toolkit for organizing and automating security assessments in an authorized, controlled practice environment.

## Initial Scope

- Target: Local DVWA (Damn Vulnerable Web Application)
- Testing framework: NeuroSploit
- Configuration loading and validation
- Finding validation and reporting

All security testing is restricted to the approved local DVWA environment.
